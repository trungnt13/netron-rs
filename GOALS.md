The ultimate objective of `netron-rs` is to be the smallest practical, fast Rust backend for inspecting ONNX and MLIR only: delete all other Netron backend code and compatibility obligations, support ONNX model/protobuf inputs and MLIR text with MLIR bytecode as the next MLIR format target, open files into indexed `ModelSession` views, keep `parse -> Model` and normalized JSON only for compatibility, golden parity, and small exports, and serve CLI, web, and VS Code clients through bounded summary, diagnostics, search, detail, tensor/resource metadata, graph/region slicing, and layout projections that remain responsive on large models without executing models, running MLIR passes, converting frameworks, eagerly loading tensor/resource payloads, or requiring full-graph/full-IR serialization or layout on open.
